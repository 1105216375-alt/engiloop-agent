## 如何复核

运行 README 中的命令。`tools/check_release.py --manifest` 可重新生成文件哈希清单；清单变化应重新审查和提交。需要实测工程准确率、延迟、token 成本或真实安全性结论时，应另建授权数据集、规则版本、评测口径和验收流程，本仓库不补造这些数据。
