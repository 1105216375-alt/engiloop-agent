# 公开版适配记录

本表记录为独立发布而做的改动，**没有回写原生产工程**。

| 范围 | 改动与理由 |
|---|---|
| 导入与配置 | 剥离原 Web 应用的启动副作用，使用相对包导入；不捆绑原配置或数据。 |
| RAG / 图谱 | 构造器显式注入索引和图，不自动搜索当前目录；无完整索引的公共入口拒绝降级冒充条款核验。 |
| 构件校验 | 从原 orchestrator 隔离别名/NMS/复合名提取，不再因缺少应用导入而悄悄跳过。 |
| 状态与日志 | 使用独立 ENGINEERING_AGENT_* 配置名；状态库必须显式指定位置；Trace 工具声明不默认列出未交付工具。 |
| 输入适配 | 保留原纯解析函数，新增离线会话、字段缺口、量测归一与 DOCX 来源定位包装。 |
| 计算器 | Python eval 改为受限 AST；禁止属性/任意调用，限制输入与数值资源；不宣称是 OS 沙箱。 |
| 评分 | 原聚合公式不变，新增显式输入校验和指定部件快照入口；不发布全桥正式等级；保留报告原值。 |
| 回退 | 修复残差状态 Enum 判断，加入实际 RuntimeController 故障注入。 |
| 记忆 | 排除回滚步骤、无候选 ID 或没有唯一 ACCEPT 对应的动作；无有效步骤不入候选记忆。 |
| 造价 | 未公开校准造价模块，不搬入私有单价，也不用默认桥长生成金额；返回 cost_model 缺口。 |
| 公开示例 | 只使用合成数据；明确哪些调用是真实代码、哪些值是夹具；不编造历史运行日志或性能数字。 |
| 首页三项演示 | 新增 `examples.showcase`：DOCX 草稿与独立证据对照、同会话逐步补证后重跑推理、显式规则包切换。独立输入追问与回滚故障注入分开标注，不伪装为同一生产流程。 |
| 规则包适配 | 新增 `engineering_agent.rulepack`：只接收合成规则的显式标度—扣分映射，调用原评分引擎；规则及输入摘要用于显式复用检查。不是自动规范解析、真实性认证或生产缓存失效服务。 |

`source-provenance.json` 记录初始源文件与导出哈希，`release-manifest.json` 记录发布版本文件哈希；两者均不是法律权属或历史时间戳证书。`nlp.py` 的纯函数来源和报告包装来源见各模块说明；新增文件、已有文件的变更可通过 Git 历史与本表追踪。
