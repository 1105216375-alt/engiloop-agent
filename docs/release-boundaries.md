# 公开发布与使用边界

本仓库公开的是工程垂域智能体的机制组合、相关桥梁适配代码和隔离复现示例，不是原产品的完整生产部署。开源代码许可不等于工程鉴定资格、安全认证或对任一具体桥梁状态的保证。

## 本次公开什么

自有代码按仓库根目录的 Apache License 2.0 许可发布，署名与来源说明见 `NOTICE`。机制源头和本轮新增适配见 [source-map.md](source-map.md)。

主要范围包括语义结构化、残差状态与候选验证、图谱与检索的内存适配、输出反向核验、确定性计算相关代码、记忆匹配与审核、状态检查点、有限状态回退和持久任务重试。各模块的可用范围以实现、测试和机制文档为准。

源文件“原样抽取”“修改后抽取”和“本次新建适配”应区分记录。公开副本中的修复不自动表示原产品已同步修复；保留原模块路径也不表示复制了生产数据库与运行环境。

## 模型、符号系统与验证器各自的边界

模型用于理解、提出候选和组织表述，不直接取得“工程结论可信”的资格。符号系统负责显式字段、规则与确定性计算、范围约束和状态控制；验证器检查当前已实现且可机械判定的主张。

这不是“零幻觉”承诺，也不是任意自然语言结论的完整形式化证明：

- 字段齐全不等于数据真实；单位归一化不等于量测经过现场核验。
- 规则计算可复现不等于输入、规则版本或适用条件正确。
- 引用存在不等于支持整句话，支持一句话也不等于适用于当前桥梁。
- 图谱中的关系与权重是建模结果，不是自动成立的因果证明。
- 记忆复用、命中分数和“已审核”状态不能替代当前任务的证据校验。
- `VerifiedFact` 等类型名称表示程序中的状态约定，其可信程度取决于实际检查器和证据。
- 未识别的自由文本错误、缺失的业务规则和未覆盖的攻击仍可能通过当前检查。

安全相关结论、正式工程评定、施工参数、养护决策与发布签发，须由有职责的专业人员按适用流程复核。系统输出不能替代现场检测或法定责任主体。

## 公开示例的数据纪律

公开示例应从显式参数或合成夹具取得输入，不自动搜索开发者桌面、原应用目录、家目录、真实数据库或既有运行配置。

默认离线演示不得偷偷启用供应商模型。使用者显式配置在线模型时，应自行确认数据传输范围与服务条件；不要将整个真实档案库或凭据拼接进提示词。

运行隔离也包括环境变量：公开版把状态与日志路径改为 `ENGINEERING_AGENT_STATE_DB`、`ENGINEERING_AGENT_TRACE_DIR`，不继承原产品的 `BIP_STATE_DB`、`BIP_TRACE_DIR` 配置。状态库须传入显式路径或设置公开版变量；公开演示应使用临时目录。`ENGINEERING_RULES_DIR` 仅是调用者提供规则包的位置，不表示规则包随代码发布或已通过适用性审核。

合成的规范、评分值和工程案例必须标明用途。它们用于展示“字段如何流转、验证如何影响结果”，不能冒充现行标准或实际工程评定依据。原实现中保留的历史兜底、默认值和启发式，也不能因此被表述为已验证的现行工程规则。

## 不可信输入与执行安全

输入边界检查和提示注入规则只能覆盖已实现模式，不能代替完整的安全隔离。公开计算器已改为有界 AST 解释器，限制语法、类型、函数和数值资源，移除了表达式 eval；它仍不是通用代码或操作系统沙箱。注册 Python callable 属于可信应用代码。面对不可信输入，还需适当的进程和资源隔离，见 [safe-arithmetic.md](safe-arithmetic.md)。

报告解析、模型生成、工具调用和审计记录也需要输入大小、运行时间和资源预算控制。对外服务部署需独立进行身份、权限、上传文件、日志脱敏和服务隔离评估，不能把本仓库的机制演示直接视作已加固的公网服务。

## 检查点和回退不是通用撤销

本仓库区分拒绝候选提交、受覆盖状态不变量触发的内存回退、持久审计检查点以及整任务重试。它们不等于任意步骤无损续跑、分布式恰好执行一次、撤回已发送工单或取消已产生的模型费用。

恢复与副作用的具体边界见 [checkpoints-and-recovery.md](checkpoints-and-recovery.md)。外部写入应另设审批、幂等协议、提交闸门和补偿机制；不能期望推理状态回退替代这些工程工作。

## 发布前检查

只对显式白名单构建发布目录，不从原应用根目录执行全量添加后再依赖忽略规则补救。每次新版本至少检查：

1. **文件清单**：没有真实资料、运行配置、日志、数据库、缓存、压缩交付包或二进制私有资产。
2. **秘密扫描**：对暂存内容和拟发布历史扫描令牌、密钥和私钥；报告只输出文件、行号、类别，不输出命中值。
3. **数据标识扫描**：检查个人/企业项目标识、真实桥名、路径、报告号与原环境地址；示例使用合成标识。
4. **来源与许可**：更新源映射、依赖声明和通知；部署方锁定其已验证的依赖版本，新引入第三方材料单独核对许可。
5. **隔离执行**：在没有私有数据、没有模型密钥的干净环境运行公开测试；缺少数据时明确报错或限定能力，不能静默假装完成权威核验。
6. **负例测试**：错误数值/数量/条款、缺失证据、对象错配、记忆越界、验证拒绝、状态回退与恢复边界应有可检查断言。
7. **文档一致**：新增适配不写成历史生产成果；合成实验不写成实测收益；未支持的能力不放进“已支持”列表。

静态扫描没有命中只表示该扫描在其覆盖范围内未发现模式，不构成“无秘密”“无漏洞”或“无幻觉”的证明。发布到托管平台、推送远端或开放公网服务是单独动作，不由本地打包和测试自动完成。
